# Architectural and scientific decision record

- Scope: Phase 1 six-compartment, closed-loop, deterministic ODE prototype. No patient data, remote deployment, or clinical prediction.
- Independently developed model and annotations. External source code is not executed. Source/license review is delegated separately.
- Compartment volumes are state variables; pressure and flow are algebraic observables. This permits direct conservation auditing.
- Ontology annotations describe mathematical variables; annotations alone do not establish biological compatibility or model validity.
- Local concepts must be explicitly distinguished from verified external ontology concepts.
- Baseline and reduced-contractility experiments use the same numerical engine, not adjusted outputs.
- Mechanistic intervention effects are parameter changes, not drug-dose predictions.
- Verification distinguishes implementation correctness, broad plausibility, and external biological validation. The latter is not established by this milestone.
- Renal feedback and clinical therapy models are deferred until the cardiovascular core passes verification.
- Roles: Agent A model/equation implementation; Agent B semantic implementation; Agent C independent scientific source review, followed by independent code verification; parent integration and reproducibility.
- Canonical experiment: 60 cycles, DOP853 rtol=1e-9, atol=1e-10 mL, max step T/200, 400 output samples/cycle. This is tighter than the core API defaults; full default-tolerance transients showed a non-negligible refinement difference.
- Milestone periodicity gate: <=0.1 mL last/prior-beat six-volume waveform difference. The broader prospective 1e-4 mL for multiple successive beats is not silently substituted or claimed complete.
- Integration review corrected SV annotation to the actual flow-integrated metric, added executable numeric bindings, and limited gauge-pressure references to pressure variables.
- Synthetic benchmark deliberately retains a false acceptance: actual RV output with falsely assigned LV metadata. Metadata validation is not numerical provenance validation.
- Package was built as a wheel, installed in a separate environment, and executed twice in isolated Python mode. Numerical CSV replay and parsed summaries matched exactly on this host; no cross-platform identity claim.
- Smith 2004 OpenCOR reference run (2026-11-01, user-approved): fixed-step RK4 replaces CVODE only, because the default run failed with a KINSOL iteration-limit error. KINSOL, model, parameters and units are unchanged; results are labelled RK4 and do not explain the CVODE failure.
- Smith 2004 run comparison (2026-11-01, user-approved): output times are treated as equal when |dt| <= 1e-9 s (far below the 5e-6 s smaller step). Applies to the time axis only; raw CSVs are not altered, and the tolerance was fixed before inspecting value differences.
- Smith 2004 RK4 value comparison (2026-11-01, user-approved): report-only, no pass/fail line. The literature read (Pathmanathan & Gray 2013 and 2014, Erdemir 2020, Santiago 2022, Mulugeta 2018) prescribes a verification procedure but no universal numeric acceptance threshold; the level is set by context of use, and this project is an exploratory prototype. Step-halving results (observed order and error per quantity of interest) are reported without being declared passed or failed. A passing result would still not establish scientific validity.
- Smith 2004 time-stamp tolerance (2026-11-01, user-approved, supersedes the 1e-9 s entry above): the 1e-9 s value was chosen by the assistant, not taken from literature. Output times count as equal when |dt| <= N_steps * eps(2.22e-16) * t_max (about 1.0e-10 s for 3.0e5 steps to 1.5 s). It rests on IEEE 754 double arithmetic, not on biomedical literature.
- Smith 2004 step sizes (2026-11-01, user-approved): a third RK4 step size, 2.5e-6 s (run C), is added to 1e-5 s and 5e-6 s so an observed order of convergence can be computed; two sizes cannot give one.
- Smith 2004 run C and scalar definitions (2026-11-01, user-approved, fixed before run C results exist): run C changes only the integration step (2.5e-6 s); the output interval stays 0.001 s as in A and B (1,501 rows each, not one row per integration step). A, B and C are compared by the same output index, with time-stamp equality checked by the derived bound above and N_steps = 1.5 / the run's integration step. Scalars: stroke volume per beat = trapezoidal integral of max(Q_av, 0) over the CSV samples; valve opening = first sample with Q_av > 0, closing = first later sample with Q_av <= 0, no interpolation; beats are 0-0.75 s and 0.75-1.5 s, with the 0.75 s sample in both. Valve times therefore have 1 ms resolution and are reported, not used as a convergence measure. The optional negative-flow integral (min(Q_av, 0)) was not adopted; negative Q_av values and their sample-time spans are only recorded. Adding it after run C results exist would no longer be fixed in advance.
- UI sample data (2026-11-01, user-approved): sample values, graphs and relations hard-coded in the separate React UI repository (read-only check of main 6433bf5, mainly `src/lib/evidence.ts` and `src/lib/ontology.ts`, reported by another agent and not seen here) are excluded from all research evidence and calculations. When real results are connected, the UI must label sample and real outputs distinctly and must not fill missing data with sample values.
- Current numerical baseline is elevated-pressure and all default values remain exploratory; no tuning was performed to manufacture normality or positive findings.
- Evidence review before any OWL (2026-11-01, per the user's brief): candidate concepts and relations for the Smith 2004 model are proposed only with a quoted source location (`docs/evidence_review/`); abstract-only sources fix no relation direction or mapping; unresolved points stay `UNKNOWN`. Numeric cross-model comparison with the CellML is blocked until the kPa-versus-mmHg label conflict (C1) is settled from the 2004 paper. The SemSim reference annotation of the model (PMR workspace 267) is treated as evidence of practice, not authority; its defects are recorded, not copied. A manual comparison group receiving the same material is designed before any ontology benefit is claimed.
- C5 bearer form (2026-11-01, user decision): adopt `Portion of blood part_of cavity/lumen` over organ-only anatomy (for example, fma9670 part_of fma9466 for the LV cavity; S9 PMR workspace 267 annotation, S11 FMA 5.1.0, `docs/evidence_review/evidence_review.md` Q1/C5). This is a project decision, not a new scientific finding or a claim of physical equivalence between lumped compartments and named lumens. Registry implementation remains unchanged (LV fma7101, RV fma7098) and deferred.
- Pressure reference (2026-11-01, user decision): pressure reference is expressed as the sink of an energy differential, following OMEX metadata specification v1.2 §2.3.7.3 and SemGen annotation protocol step 5 (`docs/evidence_review/evidence_cards.md` S16 item 9, S21). Chamber pressures P_lv, P_rv, P_ao, P_vc, P_pa, P_pu have an unspecified sink, that is the model's common ground; free-wall pressures P_lvf, P_rvf have the contents of the pericardial space as sink. The external-pressure terms in each pressure law (none for P_ao, P_vc; P_th for P_pa, P_pu; P_peri = P_pcd + P_th for P_lv, P_rv) are dependency structure, not reference points, and are recorded under Q2. Whether the common ground equals atmospheric pressure is UNKNOWN from the CellML. The FMA entity for "contents of the pericardial space" is not yet selected (fma9887 is the candidate used in S9). Documentation only; the registry `reference` string is unchanged. This supersedes the four-value vocabulary proposed earlier the same day, which classified external-pressure terms rather than reference points.
- C1 units and the R13 numeric block (2026-11-01, user decision): the canonical CellML's pressure, elastance, resistance and inertance values are read in mmHg-based units (mmHg, mmHg/mL, mmHg·s/mL, mmHg·s²/mL); its kPa labels are treated as mislabels and no conversion factor is applied. This lifts the block on numeric comparison with the CellML set in the evidence-review entry above (R13). Basis: the 2004 author manuscript uses mmHg, ml and s throughout and never kPa, including the inertance unit "L = 10^-6 mmHg s^2/ml" (`docs/evidence_review/evidence_cards.md` S6P); Paeme 2011 Tables 1-3 give the same numerals with mmHg-based units and P_th = -4 mmHg (S17); the six CellML initial volumes sum exactly to the manuscript's 1500 mL stressed volume; and the unmodified CellML run C gives P_ao 79-116, matching the manuscript's target of about 120/80 mmHg, whereas a kPa reading would mean about 590-870 mmHg. Remaining uncertainty: the manuscript tabulates no parameter values, so no individual numeral's unit is stated by the authors; values Paeme does not tabulate (R_sys, R_pul, and E_ao, which Paeme prints as 0.0) rest on the unit system and magnitudes alone. The CellML file and the OpenCOR outputs are not edited; existing outputs labelled kPa are read as mmHg. Every numeric comparison cites this entry. The structural differences C3, C7, C9 and C10 are not affected, and comparison results stay report-only under the value-comparison entry above.
